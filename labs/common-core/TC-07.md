# TC-07 — BDAT et décision d'architecture

**Statut : code de démonstration committé ; résultats de tests non confirmés par exécution CI.**  
**Sécurité :** laboratoire **strictement hors-ligne**, données inventées, sans réseau ni paiement.

## Objectif
Explorer une représentation structurée Business/Data/Application/Technology avec décision explicite.

## Prérequis
- Python **3.10 ou supérieur**, sans bibliothèque externe.
- Git facultatif pour la démonstration, recommandé pour la PR.
- Lecture des [règles de sécurité](../../SECURITY.md) et de la [fiche pédagogique](../../docs/academy/tronc-commun/TC-07-ARCHITECTURE-ET-OPEN-SOURCE.md).

## Exécution

Depuis la racine du dépôt :

```bash
# Exécute un exercice totalement local sans socket, infrastructure ni paiement.
python3 labs/common-core/runner.py TC-07

# Lance les tests unitaires du moteur couvrant les sept sujets.
# Aucun service externe ni base de données n'est requis.
python3 -m unittest discover -s labs/common-core -p 'test_*.py' -v
```

Sur Windows avec le lanceur Python : remplacer `python3` par `py -3` lorsque celui-ci est disponible.

## Travail pratique
Proposer une ADR avec avantages, limites, risques et contrôle des licences pour un lab sans réseau externe.

## Critères d'acceptation
- [ ] Le participant a consigné le système, la version Python et les commandes utilisées.
- [ ] La démonstration de `TC-07` a été exécutée et le résultat réellement observé a été reporté.
- [ ] Un scénario négatif pertinent est documenté et testé.
- [ ] Aucune donnée personnelle/financière réelle ni aucun secret n'a été utilisé.
- [ ] La contribution comporte une documentation et une revue quand disponible.

## Livrables
Une PR ou issue liée, une fiche de résultat utilisant le [modèle de preuves](EVIDENCE-TEMPLATE.md), et une explication de la **différence entre ce mock et un système bancaire réel**.

**Attention :** ce moteur est volontairement minimal et pédagogique. Il n'effectue ni HTTP réseau, ni intégration ISO 8583/20022, ni authentification réelle, ni opérations comptables contractuelles.

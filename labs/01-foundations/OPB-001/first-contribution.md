# OPB-001 — Première contribution / First contribution

## Français
1. Sélectionner un **dépôt amont officiel** depuis la matrice vérifiée.
2. Lire `README`, `CONTRIBUTING`, `CODE_OF_CONDUCT`, licence et politique de sécurité si disponibles.
3. Rechercher une tâche ouverte adaptée au niveau du contributeur; vérifier son statut actuel et les discussions existantes.
4. Pour une nouvelle idée, discuter d'abord avec les mainteneurs selon le processus du projet.
5. Reproduire localement et documenter le comportement avec des données fictives.
6. Faire un fork si prévu par le projet, créer une branche, réaliser une petite modification, exécuter les tests demandés.
7. Ouvrir une PR **uniquement lorsqu'elle respecte les règles amont**, avec explication et preuves expurgées.
8. Répondre aux commentaires des mainteneurs et reporter le résultat dans l'issue UPSTREAM OSEF.

**Ne pas présumer qu'une étiquette « good first issue » indique une tâche encore disponible sans vérification.**

## English
Select an official upstream repository. Read its README, contributing guidelines, code of conduct, license and security policy. Verify that a suitable issue is still available, discuss new proposals first, reproduce locally using synthetic data, submit a small tested PR following the project's process, and respond to maintainer feedback. Record the outcome in the OSEF upstream tracker.

# OPB-001 — Ecosystem Mapping / Cartographie de l'écosystème

[Issue de pilotage #1](https://github.com/opensource-enterprise-factory/osef-open-source-payment-banking-labs/issues/1)

## Objectif / Goal
Cartographier les solutions Open Source de banque et paiement et préparer une première contribution upstream, avec sources officielles vérifiables.

## Périmètre initial
- Apache Fineract — https://fineract.apache.org/
- Mojaloop — https://docs.mojaloop.io/
- Mifos — https://mifos.org/
- FINOS — https://www.finos.org/projects
- GNU Taler — https://taler.net/

## Livrables à produire (non réalisés)
- `project-matrix.md` : fonctionnalités, licence, gouvernance, dépôt, contribution, source et date de vérification
- `first-contribution.md` : instructions FR/EN pour une contribution amont
- `glossary.md` : vocabulaire bancaire et paiement
- `evidence.md` : preuves, incertitudes, relecture

## Méthode
1. Consulter les sources officielles (pas de fonctionnalités supposées).
2. Identifier les dépôts et règles de contribution.
3. Construire la matrice; distinguer faits vérifiés et points inconnus.
4. Repérer une opportunité réelle, sans présumer qu'elle est ouverte.
5. Préparer une proposition de contribution avec un responsable et une preuve.
6. Soumettre les livrables à une revue croisée dans une PR.

## Sécurité / Security
Laboratoire pédagogique et recherche uniquement : données fictives, aucun compte réel ni connexion aux rails de paiement de production.

## English
Map the five ecosystems, independently verify upstream repositories, licenses and contribution rules, document sources and verification dates, then prepare a first contribution proposal. No live banking or payment systems.

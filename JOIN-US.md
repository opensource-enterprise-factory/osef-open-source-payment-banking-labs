# JOIN US / Rejoignez-nous

1. Parcourez [les 20 premiers labs](labs/README.md) et leurs issues.
2. Commentez l’issue qui vous intéresse pour proposer votre aide.
3. Réalisez un test reproductible dans un environnement isolé.
4. Publiez une pull request avec documentation, scripts commentés et preuves expurgées.

N’ajoutez pas de téléphone, adresse personnelle, données clients ou secrets dans les issues publiques.

## English
Choose a lab issue, volunteer in its comments, test with synthetic data and submit a PR with sanitized evidence. No real financial data or production systems are required.

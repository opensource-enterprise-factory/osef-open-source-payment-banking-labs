## Pertinence
FINOS constitue une voie de contribution pour les ingénieurs d'Afrique francophone, notamment autour de FDC3. Distinguer la spécification standard FDC3 des implémentations et de leurs licences.

## Action / lab FDC3-001
**Rattachement :** [#61](https://github.com/opensource-enterprise-factory/osef-open-source-payment-banking-labs/issues/61), sans nouveau lab redondant.
**Objectif :** faire circuler un contexte financier synthétique entre deux applications compatibles avec une implémentation FDC3 identifiée.
**Prérequis :** Node.js, deux applications d'exemple, agent desktop compatible choisi et épinglé, données factices.
**Étapes :** installer les exemples ; émettre un contexte d'instrument fictif ; le recevoir dans la seconde application ; mesurer les erreurs et documenter les versions/licences.
**Critères de succès :** contexte identique reçu ; zéro donnée réelle ; procédure de reproduction et matrice de compatibilité.
**Meetup :** « Premières contributions FINOS/FDC3 » ; ingénieurs frontend, banques, fintechs ; 60 min, architecture + démo de communication inter-applications.

# Contributing / Contribuer

Chaque lab doit préciser : objectifs, prérequis, versions, architecture, commandes commentées, jeux de données synthétiques, tests nominaux et dégradés, critères d’acceptation, preuves expurgées, nettoyage et limites.

Une issue = un lab ; une PR = une modification relisible et testée. Respecter les licences et règles de contribution des projets amont. Aucune acceptation upstream n’est garantie.

## English
Document prerequisites, versions, architecture, commented commands, synthetic data, acceptance tests, sanitized evidence and cleanup. Follow upstream licenses and contribution policies.

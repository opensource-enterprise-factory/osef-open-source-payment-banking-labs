# Open Source Payment & Banking Labs — OSEF

**Laboratoires communautaires Open Source pour les ingénieurs d’Afrique francophone.**

[Catalogue des 20 premiers labs](labs/README.md) · [Rejoindre](JOIN-US.md) · [Contribuer](CONTRIBUTING.md) · [Code de conduite](CODE_OF_CONDUCT.md) · [Sécurité](SECURITY.md)

## Objectif
Apprendre par la pratique les systèmes bancaires, les paiements interopérables, les API, la sécurité, les données et la résilience, puis préparer des contributions aux projets Open Source amont.

**Technologies candidates :** Apache Fineract, Mojaloop, Apache APISIX, Keycloak, OpenBao, Apache Camel, Kafka, OpenTelemetry, Prometheus et Grafana. Leur intégration n’est **pas encore validée**.

## Règles impératives
Environnements isolés, utilisateurs et transactions fictifs, aucune donnée bancaire réelle, aucun accès aux rails de paiement de production. Ce dépôt ne certifie aucune conformité réglementaire ou PCI DSS.

## English
**Community-driven Open Source banking and payments labs for engineers across Francophone Africa.** Explore the [first 20 labs](labs/README.md), read [JOIN-US](JOIN-US.md), and contribute reproducible experiments with synthetic data only. No real accounts, live payment networks or production credentials. This is a learning project, not a production-ready banking platform.

# Checklist de contribution — OSEF Payment Engineer L1/L2

- [ ] Issue OSEF liée et objectif du lab compris
- [ ] Environnement, versions et commandes d'installation figés
- [ ] Données 100 % synthétiques ; aucune API d'institution réelle
- [ ] Tests de cas nominaux et négatifs écrits
- [ ] Idempotence et états terminaux vérifiés quand applicables
- [ ] Logs/traces expurgés de toute PII et de tout secret
- [ ] Licences et origine des dépendances documentées
- [ ] Rapport de tests horodaté et lié au commit testé
- [ ] README et script de nettoyage inclus
- [ ] Revue technique indépendante sollicitée
- [ ] Bug reproductible proposé upstream uniquement après vérification
- [ ] Statut de PR upstream vérifié avant toute communication

**Gate :** si une case critique manque, l'épreuve reste « en attente », sans qualification prononcée.

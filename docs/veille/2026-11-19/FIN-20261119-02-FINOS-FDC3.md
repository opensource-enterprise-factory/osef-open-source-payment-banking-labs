## Faits et réserves
La newsletter présente des résultats de recherche sur les contributions open source des institutions financières, FINOS Workspace et FDC3 3.0. Les chiffres repris dans la source se rapportent à son propre périmètre d'étude, **pas aux banques ni fintechs d'Afrique francophone**. Vérifier les annonces et dépôts source de chaque projet, y compris licences et versions des agents.

## Ce qui change
Des pistes concrètes émergent pour la gouvernance open source et l'interopérabilité entre outils métiers. Une date de mention dans une newsletter n'est pas la date de release du projet.

## Intérêt pour l'Afrique francophone
Expérimenter la circulation contrôlée de contextes entre applications financières et comprendre les modèles OSPO pour DSI, banques et intégrateurs.

## Action OSEF
Étude de faisabilité FDC3 avec deux interfaces fictives, inventaire des licences et exigences d'exploitation. Éviter de généraliser les chiffres de l'étude au marché africain.

## Lab proposé (non créé) — LAB-FDC3-001
- **Objectif :** transmettre un contexte financier **synthétique** entre deux applications via un agent FDC3 compatible.
- **Prérequis :** JavaScript/TypeScript, navigateur, documentation et agent FDC3 à licence vérifiée.
- **Étapes :** sélectionner l'agent ; figer la version ; déployer deux apps ; publier/recevoir un contexte fictif ; tester les erreurs et l'isolation.
- **Succès :** tests documentés, traces de publication/réception, incompatibilités explicites, aucune donnée réelle.
